# SNAKE 🐍🕹️

This is the Snake game experiment for the Chunk sidecars `iteration-4` workspace.

The Chunk microbuild `require-snake-md` gate (defined in
`scripts/chunk-remote-env.sh --gate-snake`) verifies that a `SNAKE.md` exists
in at least one `experiments/w_chunk-sidecars/*/src/` folder and contains the
required marker string `SNAKE 🐍🕹️` (see line above).
